# Domain

Pure fact helpers plus M3 position extraction, versioned deterministic transforms and evidence/meaning/scope/coverage preflight. Uses contracts and Node's deterministic hash implementation; no transport, UI or persistence libraries. These routines are server domain code; browser clients use contract DTOs.

All configured fields preserve original raw values, reproducible normalized values and page/position evidence. Unsupported grammar remains unresolved. Preflight does not publish. M4 adds pure identity/stage-ID/retry/lifecycle helpers here; transactional reconciliation/publication lives in the database package. [M4 limits](../../docs/milestones/M4.md).
