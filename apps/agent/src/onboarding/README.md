# Onboarding proposals

Offline DOM inspection proposes a small document-link pattern only when actual PDF links/classes exist. Operators may supply a different generic adapter config for validation against captured samples. Invented/nonmatching selectors fail validation. Results always remain needs_review.

This module cannot approve origins, grant permissions, access private pages, sign configurations or publish records. The current heuristic is intentionally narrow; unsupported patterns require reviewed configuration or a dedicated small adapter. No universal zero-code claim.
