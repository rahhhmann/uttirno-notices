## Benchmark / engine decision

One local Windows run, Node 24.19.0, Poppler 25.07.0 and Tesseract 5.5.3.20260724 with installed ben/eng traineddata. Times below are observations, not SLOs or an accuracy score.

| Synthetic PDF | Hybrid ms | OCR-only ms | Observation |
|---|---:|---:|---|
| Mixed Bangla/English text | 270 | 1355 | Text retained Bangla digits/date; OCR differed in character count |
| Table + footnote | 253 | 1391 | Text/word boxes retained; row/footnote semantics still require reviewed scope |
| Columns | 314 | 1175 | Both extracted; reading order needs review |
| Scanned mixed language | 1517 | 1595 | OCR with page boxes/confidence and mandatory review |
| Mixed text/scanned pages | 1755 | 2533 | Per-page text/OCR fallback; low-confidence page flagged |
| Malformed PDF | 50 | — | Rejected, no partial success |

Selected hybrid for intact text; force OCR is a signed source option. This compares two strategies using Poppler/Tesseract, not every available engine. No real legacy-font/poor-scan gold corpus is approved; those remain M9 source acceptance work.

## Demonstrated rejection cases

Wrong sibling qualifications; a vacancy quote masquerading as a fee; altered normalization/offsets; tampered immutable text; semantically wrong derivation; incomplete attachment/position inventory; overlapping/partial-line ranges; conflicting fee statements; payment before submission; missing scope review or approved application destination; unknown/malformed dates; date-only precision without invented midnight; missing/expired retention; source pause/revocation; immutable content conflicts; malformed model output, tool requests, unsupported facts, dropped positions, oversized bodies, context/session budgets and timeout/credential redaction.

## Practical limits / handoff

The archive is a private local backend, with hash checks and application-level immutability. Production object storage/OS isolation/purge and DB metadata are not complete. Native versions/model hashes are recorded; CI's distro tools may differ and generate different text versions.

Literal labelled-line mappings and explicit position windows are the currently implemented deterministic grammar. Free-form Bangla prose, complex/merged tables, category footnote inheritance, legacy fonts and text/image overlays need reviewed mapping/adapter work; do not infer completeness. Unknowns remain unresolved. Missing mapping is not absence. Scope/quality and coverage attestations are operator inputs for preflight, not authenticated approvals; M4/M5 must persist/revalidate their provenance and inventory.

The optional model gateway is contract-tested with mocked transport, not benchmarked against a live vendor. It accepts only deterministic-supported values and is not enabled by .env alone. No model cache persistence, durable approvals, revision publication, job UI or production release is claimed.
