## Important demonstrated cases

New ingestion cannot replace approved rows. Changed bytes at the same URL create another revision; identical replay does not. Missing memo/post identity waits for human resolution. Quotes borrowed from a sibling, unsupported application origins, incomplete position/attachment inventories, unreviewed supporting documents/quality, disabled/non-reviewer actors, self-review and stale/concurrent decisions fail closed.

Critical corrections suppress affected positions immediately. Old-document reprocessing cannot clear them; verified replacement evidence and explicit event resolution are required. Cancellation needs original-document review and cannot be reopened by exam/admit/result events. Failed fetches never create cancellation. Rejecting a critical event does not automatically restore stale facts; restoration is an explicit new decision.

External trust removal and display revocation hide public results. Source halt/config changes stop queued/in-flight work at execution/write gates. Retry/checkpoint state survives lease takeover; attempts terminate in a dead letter. Outbox claims/acks are exclusive and token-fenced. Host concurrency, minimum request intervals and long Retry-After cooldowns are exercised. Request/byte quotas persist across stages.

## Operational boundary

Current real source drafts remain unsigned/unactivated, with collection/display/retention unresolved. No real jobs, real approvals, default admin/operator account, application submission, applicant records or model provider were seeded/enabled. Default connection/startup does not crawl or migrate. The explicit db:migrate command creates schema only.

Actor ID arguments are trusted internal service context; authentication/session/CSRF APIs are M5. Production DB grants, worker OS egress/memory isolation, S3 deployment, automatic retention purge, restore/load and real gold-set/source acceptance remain M8/M9. The public projection helper is an internal bounded read, not a finished public API/search/pagination contract.

Automatic reconciliation assumes fixture-reviewed numbering/memo meaning. Arbitrary event prose, missing per-document mappings, artifact drift, complex tables or applicable supporting conditions require review/adaptation; synthetic tests do not establish nationwide completeness or production accuracy. Raw artifacts remain in the private local archive; no public binary endpoint exists.
