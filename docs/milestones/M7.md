## Integration and production limits

No new third-party dependency, migration, account, live provider, source approval or production configuration. Root lockfile adds only three workspace dependency declarations. API/agent/database behavior is reused, not rewritten. Source gates and independent publication remain unchanged.

Real recruiting-site calls are absent from ordinary tests. The first public browser cases use real PostgreSQL/API for draft invisibility, independent publication and source display revocation. A separately labelled synthetic HTTP fixture covers open/closed/stale/conflicting/cancellation display and pagination; it is not proof of real evidence correctness or source permission. Source text remains escaped; no remote HTML/PDF runs in the portal.

Actual Uttirno router/assets/canonical hosting and approved preparation destinations remain Q08. No consumer SSO/CV/entitlements/saved-job/notification features were added.

Selected axe A/AA, mobile overflow and keyboard checks do not establish full WCAG compliance. Native isolation, real deployment, load/restore/security operations and real source/gold-set acceptance remain M8/M9. No production-readiness claim.
