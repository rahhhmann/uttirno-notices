## Failures discovered and corrected
Initial compiler API tooling was incompatible with the selected TypeScript version; static analysis now uses Babel and is tested. Invalid URL refinement could throw before sanitized configuration errors; fixed and regression-tested. A combined-process web smoke reused Next runtime state; web apps now run in separate processes with explicit non-zero failure propagation. Assertions were not relaxed.

## Deliberate limits
No production source permissions/activation, generic fetch policy/adapters, full PDF/OCR, real job extraction, job schema/migrations/seeding, publication, authentication, job UI, scheduling or production hosting. No real source crawl occurred. The 25 tests are foundation verification, not gold-set extraction accuracy, security certification, accessibility/browser E2E or full production acceptance.

The installed native PostgreSQL on port 5432 was not modified; testing used isolated port 55432. LocalStack is a development emulator only. Dependency audit is time-specific. npm reported an unapproved esbuild postinstall script; no blanket lifecycle-script approval was granted, and the checked builds/tests ran successfully with installed platform packages.

The CI workflow is defined and the equivalent commands were executed locally. Remote CI outcome must be checked separately; do not infer it from this document.
