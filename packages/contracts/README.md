# Contracts

M1 evidence/value envelopes remain supported. M3 adds document pages/word boxes/quality flags, immutable lineage, full position fields, located evidence, strict candidate/status envelopes and versioned extraction-plan schemas.

M4 adds strict stage identity, multi-document revision bundle, attachment/position inventory and lifecycle-event vocabulary schemas. These are data contracts, never actor authorization or publication approval.

Shape validation alone is not factual verification. Domain reproduction, original-document/scope review, current policy and durable publication approval are independent gates. Arbitrary original titles are data, not an enum. [Extraction](../../docs/EXTRACTION.md).
